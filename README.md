TALLER INTEGRADOR – GRAFOS DIRIGIDOS

Proyecto: Sistema de grafos dirigidos utilizando arquitectura MVC en C#.

Descripción

Este proyecto implementa un grafo dirigido para representar relaciones entre usuarios mediante vértices y aristas.

Se desarrolló utilizando el lenguaje C# y una estructura basada en el patrón Modelo-Vista-Controlador (MVC).

Funcionalidades

* Agregar y eliminar vértices.
* Agregar y eliminar aristas dirigidas.
* Consultar vecinos de un vértice.
* Recorridos BFS (búsqueda en anchura).
* Recorridos DFS (búsqueda en profundidad).
* Detección de ciclos.
* Cálculo de grados de entrada y salida.
* Identificación de usuarios influyentes y activos.
* Identificación de usuarios sin seguidores.
* Comprobación de alcanzabilidad entre vértices.
* Representación textual del grafo.

Estructura del proyecto

* Models: contiene las clases Vertex, Edge y Graph.
* Controllers: contiene GraphController, encargado de gestionar las operaciones del grafo.
* Program.cs: contiene el punto de entrada y las pruebas de funcionamiento.

Tecnologías

* Lenguaje C#
* Arquitectura MVC
* Estructuras de datos y algoritmos de grafos dirigidos
